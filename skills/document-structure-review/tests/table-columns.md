# 표의 열 분리 검증

평가자에게 [스킬](../SKILL.md)과 [검토 자료](fixtures/table-columns-original.md)만 제공한다. 사본에 `$document-structure-review`를 수정 모드로 적용하고, 같은 원문의 다른 사본에는 `review` 모드를 적용한다. 아래 판정 기준은 평가자에게 제공하지 않는다.

| 표 | 기대 결과 |
| --- | --- |
| 지급 필드 | `자료형`, `null 허용`, `키 제약`, `의미`를 별도 열로 둔다. `amount`의 `bigint`와 원 단위, `settlementId`의 PK·FK, `receiptNo`의 `text`와 null 허용 및 접수번호의 출처를 원래 행에 보존한다. |
| 조회 기록 필드 | `저장 정보` 열 전체를 읽고 `자료형`과 `의미`를 분리한다. `id`의 `uuid`와 `checkedAt`의 의미처럼 개별 셀에 값이 하나뿐이어도 열 안에서 종류가 바뀌는 부분을 고친다. |
| 조회 메서드 | `payoutId: UUID`는 한 매개변수의 표기이므로 `입력` 열에서 유지한다. |

두 필드 표에서 주어지지 않은 자료형·의미·제약은 덧붙이지 않는다. 수정 모드는 표 자체를 바꿔야 한다. 리뷰 모드는 두 필드 표의 문제와 나눌 열을 지적하고 파일을 원문과 바이트 단위로 일치하게 유지한다.
