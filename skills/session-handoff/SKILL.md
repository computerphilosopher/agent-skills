# Session Handoff

다음 세션이 현재 작업을 이어가는 데 필요한 정보만 전달한다. 사용자의 언어로 짧게 작성한다.

## 남길 내용

- 작업 위치와 이어갈 주제를 한 줄로 식별한다. 문서 검토만 하는지 등 현재 세션에만 적용되는 범위가 있으면 짧게 덧붙인다.
- 아직 파일에 반영되지 않은 결정, 미결 질문, 진행 중 작업과 다음 행동을 남긴다. 확정·제안·철회를 구분하고 가장 최근 사용자 결정을 따른다.
- 파일이나 커밋에서 바로 확인할 수 있는 완료 내역은 반복하지 않는다. 현재 작업을 이해하는 데 꼭 필요한 기준 위치만 연결한다.
- 공통 작업 규칙은 `AGENTS.md` 등 해당 원문을 따르도록 한 줄로 갈음한다. 검사 명령·커밋 규칙·일반 주의사항을 복사하지 않는다.
- Git 작업이면 현재 checkout·브랜치, 미커밋 변경 유무와 소유 작업, 푸시 여부를 필요한 만큼 적는다. 실제 상태를 확인하고 확인하지 못한 사실은 단정하지 않는다. 기본 checkout과 별도 worktree를 구분한다. 보존해야 할 다른 작업이 있으면 짧게 표시한다.

## 작성 방식

기본은 채팅에 복사 가능한 짧은 텍스트 블록 하나다. 파일 저장은 요청받은 경우에만 한다. 인수인계 요청 자체를 커밋·푸시·새 채팅 생성 요청으로 해석하지 않는다.

대화의 경과, 시행착오, 이미 철회한 제안, 커밋 목록, 검사 결과 나열을 넣지 않는다. 남은 논의가 없으면 없다고 짧게 적으며 빈 항목을 만들지 않는다. 별도 형식이나 상세 인수인계를 요청받으면 그 범위에 맞춘다.

보내기 전에 각 문장을 확인한다. 저장소에서 확인할 수 있는 내용을 반복하는지, 논의안을 확정처럼 적었는지, 다음 세션의 판단에 필요하지 않은 설명인지 살펴보고 덜어낸다. 간결함 때문에 미반영 결정이나 작업을 막는 핵심 정보를 버리지는 않는다.
