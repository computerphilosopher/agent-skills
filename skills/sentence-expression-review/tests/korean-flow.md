# 문단 가독성 검증

평가자에게 [문장강화](../../munjang-ganghwa/SKILL.md), 연결된 스킬, [검토 자료](fixtures/korean-flow-original.md)를 제공한다. 문장 표현만 검토하도록 요청하고, 같은 원문으로 기본 수정 모드와 `review` 모드를 각각 실행한다. 판정 기준은 평가자에게 제공하지 않는다.

| 사례 | 기대 결과 |
| --- | --- |
| 1 | 제출 규칙을 읽으려면 예외를 먼저 이해한 뒤 ‘해당하는 경우가 없으면’에 적용해야 하는 부담을 짚는다. 이용한 달의 마지막 날까지 제출해야 한다는 규칙을 먼저 쓰고, 이미 냈다면 다시 낼 필요가 없다는 예외를 이어 쓴다. |
| 2 | 재요청 가능 여부를 알려면 증빙 안내를 지나 문단 끝까지 읽은 뒤 첫 문장으로 돌아가야 함을 짚는다. 미지급 조건을 재요청 가능 여부와 한곳에서 읽게 하고, 처음 낸 증빙을 다시 낼 필요가 없다는 뜻을 보존한다. |
| 3 | 예정일이 정해질 가능성과 정산 이후라는 조건을 보존한다. 예정일을 누가 정하는지와 실제로 정해지는지는 원문의 범위 안에서 표현한다. |
| 4 | 단정적인 어조와 부정 표현을 사용해도 적용 범위가 바로 이해되므로 유지한다. |

수정 모드에서는 1·2번의 수정이 문서에 반영되어야 한다. `review` 모드에서는 원문을 유지하면서 1·2번의 읽기 부담과 수정 방향을 보고해야 한다. 어미나 단어의 일치 여부로 판정하지 않는다.
