# 문서 가독성 리뷰

독자가 필요한 설명을 찾고 문서의 흐름을 따라 내용을 이해할 수 있는지 검토한다. 리뷰 요청에는 발견 사항을 보고하고, 수정까지 요청받으면 뜻을 유지하며 구성을 다듬는다.

## 검토 범위

대상 독자와 문서의 목적에 맞춰 설명의 충실도와 배치를 검토한다. 문서에 정해진 의미·정책·설계와 원문 인용·자료 제목을 보존한다.

문장 표현과 불필요한 부연의 검토는 [문장 표현 리뷰](../sentence-expression-review/SKILL.md)에서 맡는다.

## 심각도

새 세션에서도 현재 문서를 독립적으로 검토하고 아래 기준을 적용한다. 이전 리뷰 내역은 필요하지 않다. 심각도는 대상 독자의 이해와 행동에 미치는 영향으로 정한다.

| 등급 | 판정 기준 | 처리 |
| --- | --- | --- |
| `critical` | 핵심 의미를 잘못 이해하거나 잘못된 행동을 할 수 있다. 구체적인 오해나 행동을 근거로 제시한다. | 반드시 수정 |
| `warn` | 필요한 의미나 다음 단계를 확정하기 어려워 독자가 추측해야 한다. 답할 수 없는 구체적인 질문을 제시한다. | 반드시 수정 |
| `info` | 의미와 절차는 명확하지만 불필요한 반복이나 읽기 부담을 줄일 수 있다. | 선택적 개선 |

단순 취향 차이는 지적에서 제외한다. 문장 길이, 제목 형식, 비교 문서와의 차이만으로 심각도를 높이지 않는다. 명시적 필수 작성 규칙 위반은 심각도와 별도로 표시하고 해당 규칙을 근거로 제시한다.

## 검토 절차

1. 대상 문서에 적용되는 작성 규칙을 확인하고 본문·제목·표·예시를 읽는다. 연결된 정의는 용어와 설명을 이해하는 데 필요한 범위에서 확인한다.
2. 저장소 문서라면 문서 인덱스와 관련 디렉터리를 검색해 목적·독자층이 비슷한 현행 문서를 선정한다. 직접 링크 밖의 유사 문서도 확인하되, 사용자가 정한 비교 범위를 따른다. 대표 문서의 본문을 읽고 아래 일관성 기준으로 필요한 내용을 얼마나 구체적으로 설명하는지 먼저 확인하고, 설명의 배치와 표의 구성을 대조한다.
3. 모든 검토 기준을 확인하고 후보 지적과 수정 방향을 정리한다.
4. 보고 전에 각 후보의 주변 문맥·연결된 정의·작성 지침을 다시 확인한다. 다른 위치에 설명이 있거나 의도적으로 형식을 달리한 근거가 있는지 살피고, 제안이 의미를 유지하면서 읽기 부담을 줄이는지 확인한다. 새 내용이나 설계를 정해야 해소되는 차이는 추가 작성·결정이 필요한 항목으로 구분한다.

## 검토 기준

### 기존 문서와의 일관성

- 비교 문서와 작성 지침에서 독자가 기대하는 설명 항목을 파악한다. 각 항목이 어떤 질문에 답하며 개요·상세 정의·관계 설명·절차 중 어디까지 제공하는지 확인한다.
- 항목별로 대상 문서에 동등한 설명이 있는지, 개요나 이름 나열에 그치는지, 아예 없는지 구별한다. 동등성은 독자가 같은 질문에 답할 수 있는지로 판단한다. 다른 절이나 연결 문서가 설명을 맡는다면 실제 내용을 확인한다.
- 예를 들어 비교 문서는 대상의 이름·역할·관계·동작 조건을 설명하고 대상 문서는 이름과 역할만 나열한다면, 관계와 동작 조건의 설명 차이를 기록한다. 양쪽에 개요 표가 있어도 상세 수준은 다르다. 대상 문서의 목적에도 그 설명이 필요한지 확인해 보완 필요 여부를 판단한다.
- 장절 구성과 표의 양식을 대조하고, 같은 개념에 일관된 용어를 쓰는지 확인한다. 차이는 적용 지침과 목적·독자층·작성 단계에 비추어 통일할 부분과 유지할 부분으로 구별한다. ‘초안’ 같은 상태 표시만으로 빠진 설명이나 낮은 상세 수준을 정당화하지 않는다.
- 최신 사용자 지침을 우선한다. 기존 문서끼리 기준이 다르거나 차이를 유지할 근거가 불분명하면 확인이 필요한 차이로 남긴다.

### 구성

- 제목은 하나의 중심 주제나 목적을 드러내야 한다. 독립 주제를 구분자나 ‘및’, ‘와/과’로 나열해 제목을 붙였다면 아래 통합·분리 기준으로 구성을 검토한다.
- **상하위 관계:** 하위 절은 상위 장·절의 주제를 구체화하거나 그 안의 질문에 답해야 한다. 상위 주제를 벗어난 내용은 맞는 위치로 옮기고, 제목 단계가 내용의 포함 관계를 드러내는지 확인한다.
- **같은 수준의 역할:** 나란한 절은 각자 답하는 질문과 다루는 범위가 구별되어야 한다. 같은 묶음 안에서 분류 기준과 설명 수준이 일관되는지 확인한다. 한 절이 다른 절 전체를 포함하거나 같은 내용을 중복해서 맡으면 위계나 경계를 조정한다.
- **세분화 정도:** 짧은 문단마다 제목을 붙이거나 불필요하게 깊은 하위 절을 만들어 읽는 흐름을 끊는지 확인한다. 독립적으로 찾을 필요가 없는 보충 설명은 문단이나 목록으로 풀고, 짧더라도 별도로 찾아볼 이유가 있는 절은 유지한다. 길이나 단계 수만으로 판단하지 않는다.
- **통합·분리 기준:** 같은 질문에 답하며 함께 읽어야 이해되는 인접 절은 합치는 방향을 검토한다. 한 절 안에서 주제·독자의 작업·설명 목적이 바뀌고 각각 따로 찾아볼 필요가 있으면 나눈다. 재구성 뒤에는 한 절의 중심 주제가 선명해지고 앞뒤를 오가는 부담이 줄었는지 확인한다.
- 개념 설명에서 세부 조건과 예시로 자연스럽게 이어지는지 확인한다. 한 동작이나 변형의 설명을 여러 절에 흩어 놓아 반복 이동을 요구하지 않는다.
- 독자가 필요한 지점에서 의미·조건·참조 정보를 찾을 수 있는지 확인한다. 본문·표·예시 등 설명 형식과 위치는 내용을 이해하고 찾아보기 쉬운 쪽으로 선택한다.
- 굵은 글씨·따옴표 등 강조가 많아 중요한 내용이 구별되지 않거나, 괄호 속 부연이 읽는 흐름을 끊는지 확인한다. 강조는 중요도를 드러내는 데 쓰고, 흐름을 끊는 부연 중 필요한 설명은 적절한 본문 위치로 옮긴다.

### 표

표가 무엇을 비교하거나 찾아보기 위한 것인지 먼저 확인하고, 그 목적에 맞게 정보를 나눴는지 검토한다.

- **표의 분리:** 서로 다른 목적이나 비교 기준이 필요한 내용을 하나의 표에 억지로 합쳤는지 확인한다. 항목 묶음마다 필요한 열이 달라 빈칸·해당 없음이 반복되거나 같은 열의 의미가 바뀐다면, 목적과 비교 기준별로 표를 나누는 편이 이해하기 쉬운지 검토한다. 표의 개수나 크기보다 각 표의 역할과 표 사이를 오가며 비교해야 하는 부담을 기준으로 판단한다.
- **행·열·셀의 의미:** 행과 열의 분류 기준이 명확하고 일관되는지, 각 셀의 내용이 해당 행과 열의 의미에 맞는지 확인한다.
- **정보량:** 긴 설명이나 여러 독립 항목이 한 셀에 몰려 비교·탐색을 방해하는지 확인한다. 요약과 상세를 구분하거나 본문·목록으로 옮기되, 간결함보다 이해에 필요한 정보를 보존하는 것을 우선한다.

### 용어

- 본문·표·예시 전체에서 같은 개념에는 같은 용어를 쓰고, 서로 다른 개념을 같은 이름으로 표현해 혼동시키지 않는지 확인한다.
- 약어와 전문 용어는 대상 독자의 지식 수준에 맞게 설명하고, 낯선 용어의 뜻을 필요한 곳에서 알 수 있게 한다.

### 처리 흐름

절차를 설명하는 문서는 처음부터 결과까지 흐름을 따라갈 수 있는지 확인한다.

- 단계의 순서와 연결을 드러내고, 각 단계의 결과가 다음 단계로 어떻게 이어지는지 설명한다.
- 조건에 따른 분기와 합류 지점을 구분해 일반적인 진행과 예외 상황을 따라갈 수 있게 한다.
- 일부 과정만 발췌했다면 설명하는 범위와 생략된 부분을 밝혀 전체 과정으로 오해하지 않게 한다.

## 결과 보고

검토 순서와 관계없이 독자의 이해를 크게 방해하는 항목부터 **[심각도] 위치 → 독자에게 미치는 영향 → 수정 방향**으로 보고한다. 같은 원인의 반복은 묶고, 필요하면 짧은 수정 예시를 제시한다. 의미가 불명확하면 가능한 해석을 밝히고 임의로 확정하지 않는다. 새 내용이나 설계 결정이 필요한 부분은 별도로 표시한다.

저장소 문서의 일관성 비교에는 다음 근거를 남긴다.

- 비교 문서의 경로와 선정 이유, 대조한 설명 항목·상세 수준·표현 형식과 판단.
- 차이가 있는 경우 양쪽 근거 위치와 독자가 얻을 수 있는 정보의 차이. 누락 지적에는 대상 문서에서 확인한 범위.
- 적절한 문서를 찾지 못했거나 열람할 수 없었다면 검색 범위와 한계.

차이가 없는 경우에도 비교 결과를 남긴다. 비교를 수행하지 못했다면 그 이유와 검토 한계를 보고하고 아래 종료 기준에 따라 판정한다.

검토한 문서와 주변 설명의 범위, 불필요한 설명 검토 결과를 짧게 적는다. 지적에는 삭제·통합·이동 중 적절한 조치를 제시하고, 이동이 필요하면 설명을 맡을 위치를 밝힌다. 수정까지 요청받은 경우 관련 문맥과 표를 다시 읽어 의미 보존 여부와 새 중복을 확인한다.

## 종료 기준

검토한 범위에 대해 다음과 같이 판정한다.

- **수정 필요:** 미해결 `critical`·`warn` 또는 명시적 필수 작성 규칙 위반이 있다.
- **리뷰 완료 — 선택적 개선 있음:** 필수 수정 항목 없이 `info`만 남았다. 선택적 개선을 위해 리뷰를 계속할 필요는 없다.
- **리뷰 완료:** 미해결 지적이 없다.

필요한 내용을 읽지 못했다면 미검토 범위와 한계를 밝히고 완료 판정을 유보한다. 적절한 비교 문서가 없다는 이유만으로 완료를 막지는 않는다. 지적이 전혀 없어야 끝나는 것이 아니라, 필요한 검토를 마치고 필수 수정 항목이 없으면 끝난다.
