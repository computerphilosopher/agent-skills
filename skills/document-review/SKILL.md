# 문서 가독성 리뷰

독자가 문장을 반복해서 읽거나 여러 정의를 오가며 추측하지 않아도 내용을 이해할 수 있는지 검토한다. 리뷰 요청에는 발견 사항을 보고하고, 수정까지 요청받으면 뜻을 유지하며 표현과 구성을 다듬는다.

## 검토 범위

대상 독자와 문서의 목적을 파악하고 본문·제목·표·예시를 함께 읽는다. 연결된 정의는 용어와 설명을 이해하는 데 필요한 범위에서 확인한다. 대상 문서에 적용되는 작성 규칙을 존중한다.

문서에 정해진 의미·정책·설계를 유지하며, 독자의 이해를 방해하는 표현과 구성을 검토한다. 원문 인용과 원래 자료의 제목은 보존한다.

## 기존 문서와의 일관성

저장소 문서를 리뷰할 때는 문장별 검토에 앞서 다음 비교를 수행한다. 사용자가 비교 범위를 제한했다면 그 범위를 따른다.

1. 문서 인덱스와 관련 디렉터리를 검색해 목적·독자층이 비슷한 현행 문서를 찾는다. 대상 문서의 직접 링크 밖에 있는 유사 문서도 확인한다.
2. 대표 문서를 선정하고 실제 본문을 읽어 장절 구성, 표의 양식, 용어와 문장 표현을 대조한다. 파일명이나 목차 확인만으로 비교를 끝내지 않는다.
3. 공통된 양식과 표현에서 벗어난 부분을 찾아 통일할 부분과 내용·용도 차이로 유지할 부분을 구별한다. 적용되는 작성 규칙과 최신 사용자 지침을 우선하며, 기존 문서끼리 양식이 다르면 그 차이도 밝힌다.

리뷰 결과에는 비교 문서의 경로와 선정 이유, 실제로 대조한 양식·표현과 판단을 짧게 남긴다. 일관성 지적에는 대상과 비교 문서의 근거 위치를 함께 제시한다. 차이가 없어도 비교 결과를 적고, 적절한 문서를 찾지 못했거나 열람할 수 없었다면 검색 범위와 한계를 밝힌다. 이 비교 결과 또는 수행하지 못한 이유가 있어야 저장소 문서 리뷰를 완료한 것으로 본다.

## 문장

- 누가 무엇을 하는지, 어떤 조건에서 어떤 결과가 나오는지 직접 설명한다. 추상어·명사 나열·생략된 주어 때문에 독자가 동작을 추측해야 하는 부분을 찾는다.
- 한 문장에 독립적인 주장이나 여러 조건이 얽혀 있으면 의미 단위로 나눈다. 조건과 결과, 원인과 효과가 가까이 있도록 배치한다.
- 긴 수식어와 겹친 명사구 때문에 무엇이 무엇을 꾸미는지 모호한 부분을 찾는다. 수식어를 대상 가까이 옮기거나 문장으로 풀어 수식 관계를 드러낸다.
- 번역투·이중 피동·겹친 완곡 표현이 뜻을 파악하기 어렵게 하거나 문장을 불필요하게 늘리면 자연스럽고 직접적인 표현으로 다듬는다. 표현의 등장이나 횟수보다 문맥에서의 이해 부담을 기준으로 삼고, 원문의 가능성·유보·의무 의미를 유지한다.
- ‘~가 아니다’, ‘~는 하지 않는다’처럼 쓰지 않는 대안과 구별하거나 당연한 제외를 덧붙일 뿐인 문장은 삭제한다. 구체적인 오해를 막거나 필요한 제약을 전달하는 부정문은 적용 조건과 효과가 드러나게 유지한다.
- 간결하게 줄이더라도 의미·단위·대상·예외가 사라지지 않게 한다. 길이 자체보다 한 번 읽고 이해할 수 있는지를 판단한다.

## 구성

- 제목은 하나의 중심 주제나 목적을 드러내야 한다. 독립 주제를 구분자나 ‘및’, ‘와/과’로 나열해 제목을 붙였다면 아래 통합·분리 기준으로 구성을 검토한다.
- **상하위 관계:** 하위 절은 상위 장·절의 주제를 구체화하거나 그 안의 질문에 답해야 한다. 상위 주제를 벗어난 내용은 맞는 위치로 옮기고, 제목 단계가 내용의 포함 관계를 드러내는지 확인한다.
- **같은 수준의 역할:** 나란한 절은 각자 답하는 질문과 다루는 범위가 구별되어야 한다. 같은 묶음 안에서 분류 기준과 설명 수준이 일관되는지 확인한다. 한 절이 다른 절 전체를 포함하거나 같은 내용을 중복해서 맡으면 위계나 경계를 조정한다.
- **세분화 정도:** 짧은 문단마다 제목을 붙이거나 불필요하게 깊은 하위 절을 만들어 읽는 흐름을 끊는지 확인한다. 독립적으로 찾을 필요가 없는 보충 설명은 문단이나 목록으로 풀고, 짧더라도 별도로 찾아볼 이유가 있는 절은 유지한다. 길이나 단계 수만으로 판단하지 않는다.
- **통합·분리 기준:** 같은 질문에 답하며 함께 읽어야 이해되는 인접 절은 합치는 방향을 검토한다. 한 절 안에서 주제·독자의 작업·설명 목적이 바뀌고 각각 따로 찾아볼 필요가 있으면 나눈다. 재구성 뒤에는 한 절의 중심 주제가 선명해지고 앞뒤를 오가는 부담이 줄었는지 확인한다.
- 개념 설명에서 세부 조건과 예시로 자연스럽게 이어지는지 확인한다. 한 동작이나 변형의 설명을 여러 절에 흩어 놓아 반복 이동을 요구하지 않는다.
- 독자가 필요한 지점에서 의미·조건·참조 정보를 찾을 수 있는지 확인한다. 본문·표·예시 등 설명 형식과 위치는 내용을 이해하고 찾아보기 쉬운 쪽으로 선택한다.
- 굵은 글씨·따옴표 등 강조가 많아 중요한 내용이 구별되지 않거나, 괄호 속 부연이 읽는 흐름을 끊는지 확인한다. 강조는 중요도를 드러내는 데 쓰고, 흐름을 끊는 부연 중 필요한 설명은 적절한 본문 위치로 옮긴다.

## 표

표가 무엇을 비교하거나 찾아보기 위한 것인지 먼저 확인하고, 그 목적에 맞게 정보를 나눴는지 검토한다.

- **표의 분리:** 서로 다른 목적이나 비교 기준이 필요한 내용을 하나의 표에 억지로 합쳤는지 확인한다. 항목 묶음마다 필요한 열이 달라 빈칸·해당 없음이 반복되거나 같은 열의 의미가 바뀐다면, 목적과 비교 기준별로 표를 나누는 편이 이해하기 쉬운지 검토한다. 표의 개수나 크기보다 각 표의 역할과 표 사이를 오가며 비교해야 하는 부담을 기준으로 판단한다.
- **행·열·셀의 의미:** 행과 열의 분류 기준이 명확하고 일관되는지, 각 셀의 내용이 해당 행과 열의 의미에 맞는지 확인한다.
- **정보량:** 긴 설명이나 여러 독립 항목이 한 셀에 몰려 비교·탐색을 방해하는지 확인한다. 요약과 상세를 구분하거나 본문·목록으로 옮기되, 간결함보다 이해에 필요한 정보를 보존하는 것을 우선한다.

## 중복

대상 문서와 직접 연결된 설명에서 같은 내용의 반복이 읽는 흐름을 끊거나 불필요하게 분량을 늘리는지 확인한다.

- 제목·상태 표시·범위 안내·앞선 정의에서 이미 전달한 사실을 본문에서 다시 설명하는지 확인한다. 새로운 조건·이유·판단 정보를 더하지 않는 부연과, 이름을 그대로 풀어 쓴 설명은 덜어낸다.
- 여러 위치에서 같은 상세 설명을 되풀이한다면 한곳에 모으고 필요한 요약과 연결을 둔다. 여러 항목에 공통으로 적용되는 설명도 독자가 적용 범위를 알 수 있게 정리한다.
- 이해를 돕는 요약, 비교에 필요한 반복값, 독립적으로 읽는 구간에 필요한 설명은 유지한다. 반복 여부만으로 삭제를 판단하지 않는다.
- 정리할 때 한쪽에만 있던 이유·제약·예외를 보존한다. 연결된 위치에서 실제 설명을 찾을 수 있는지 확인한다.

## 용어

- 본문·표·예시 전체에서 같은 개념에는 같은 용어를 쓰고, 서로 다른 개념을 같은 이름으로 표현해 혼동시키지 않는지 확인한다.
- 약어와 전문 용어는 대상 독자의 지식 수준에 맞게 설명하고, 낯선 용어의 뜻을 필요한 곳에서 알 수 있게 한다.
- 이름이 대상·단위·시점과 의미를 드러내는지 확인한다. 예상과 실제, 시점과 기간처럼 혼동하기 쉬운 개념을 구별한다.

## 처리 흐름

절차를 설명하는 문서는 처음부터 결과까지 흐름을 따라갈 수 있는지 확인한다.

- 단계의 순서와 연결을 드러내고, 각 단계의 결과가 다음 단계로 어떻게 이어지는지 설명한다.
- 조건에 따른 분기와 합류 지점을 구분해 일반적인 진행과 예외 상황을 따라갈 수 있게 한다.
- 일부 과정만 발췌했다면 설명하는 범위와 생략된 부분을 밝혀 전체 과정으로 오해하지 않게 한다.

## 결과 보고

독자의 이해를 크게 방해하는 항목부터 **위치 → 이해하기 어려운 이유 → 수정 방향**으로 보고한다. 같은 원인의 반복은 묶고, 필요하면 짧은 수정 예시를 제시한다. 의미가 불명확하면 가능한 해석을 밝히고 임의로 하나를 선택하지 않는다. 취향 차이와 실제 이해의 장애를 구별한다.

검토한 문서와 주변 설명의 범위, 위 일관성 비교 결과, 중복 검토 결과를 짧게 적는다. 수정한 경우 관련 문맥과 표를 다시 읽어 의미를 잃거나 새 중복을 만들지 않았는지 확인한다.
