# UI 리뷰

**쓸데없는 텍스트와 쓸모없는 버튼을 찾아 줄인다.**

## 텍스트

당연한 설명, 같은 내용의 반복, 화면을 보면 알 수 있는 조작 안내를 찾는다. 문구를 빼도 사용자가 이해하고 진행할 수 있으면 삭제한다. 필요한 안내는 짧고 정확하게 쓴다.

## 버튼

역할이 겹치거나 현재 상황에서 쓸모없는 버튼을 찾는다.

## 리뷰 결과

어디의 무엇을 없애거나 줄일지, 이유와 함께 짧게 보고한다. 삭제만으로 충분하면 대체 문구나 새 버튼을 만들지 않는다. 동작을 확인할 수 없으면 추측으로 삭제를 권하지 않는다.

리뷰 요청에는 발견 사항을 보고하고, 수정까지 요청받으면 반영한다.
